灵桥小球 v0.1.1 使用说明
========================

【这是什么】
不用开 VS Code 的灵桥：桌面上一个悬浮小球，把你选的文件夹通过 MCP 交给网页 AI（Hark 等）读写、运行命令。

【第一次使用】
1. 把整个 LingoBall 文件夹解压到一个固定位置（比如 D:\LingoBall），不要直接在压缩包里运行。
2. 双击 LingoBall.exe。
   如果 Windows 提示“Windows 已保护你的电脑”，点“更多信息”→“仍要运行”（程序没有购买数字签名）。
3. 面板会自动弹出：
   - 选择工作文件夹（AI 只能访问这个文件夹）
   - 隧道选 ngrok，填 Authtoken 和固定域名，点“保存 ngrok 设置”
   - 点“启动”
4. 第一次启动会自动下载约 30MB 的 Node 运行环境（国内镜像），之后不用再下。
5. 显示“运行中”后，MCP 地址已自动复制，发给 AI 即可。

【日常操作】
- 左键点小球：打开/收起面板
- 右键点小球：快捷菜单（启动/停止、复制地址、切换隧道、退出）
- 拖动小球：随意摆放，靠近屏幕边缘会自动吸附
- 小球外圈颜色：灰=未启动，黄色转圈=启动中，绿=运行中，红=出错
- 小球右上角闪红点：AI 在等你审批

【自动更新】
- 小球启动 20 秒后、之后每 6 小时检查一次新版本；有新版会弹通知，面板顶部点“立即更新”，小球会自动重启成新版本。
- 也可以在面板底部点“检查更新”。

【注意】
- 小球和 VS Code 里的灵桥插件不要同时启动：它们会抢同一个 ngrok 固定域名。
- 小球有自己的访问令牌，和 VS Code 插件的不一样，第一次用要把小球的新地址发给 AI。
- 地址里包含访问令牌，不要公开分享；泄露了就在面板底部点“重置令牌”。
- 面板需要 Microsoft Edge WebView2（Win10/11 基本都自带）。没有的话右键菜单照样能用。

【文件位置】
- 设置：%APPDATA%\LingoBall\config.json
- 运行环境、ngrok、日志：%LOCALAPPDATA%\LingoBall\
- 卸载：退出小球，删除程序文件夹和上面两个文件夹即可；开机自启记得先在面板里关掉。
